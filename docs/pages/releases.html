    Change Log

    For a detailed list of citations and workflow, please visit the authors page.

    FIREDpy 2.1, 2000-2024 datasets (10/14/2024):

    • No longer using setup.py. See new instructions for running it with Docker or installing it locally.
    • Improved fire grouping
    • Improved CLI
    • Access to MODIS burn area product Version 6.1

    FIREDpy 2.0 Description of 2000 - 2021 data sets (6/30/2022):

    • Improved efficiency and flexibility of the underlying algorithm
    • Now supports optional land-cover, ecoregion attributes, and fire characteristics like area, duration, and growth.

    FIREDpy 1.0 Description of 2001–2019 data sets: (10/24/2020):

    • Created Python CLI for downloading MODIS Collection 6 burned-area data and grouping detected burns into individual fire events.
    • Users can adjust the spatial and temporal thresholds to define events for different regions and research needs.
    • Tracks repeated burns within a year and fires that cross calendar years without splitting them at year-end.
    • Generates fire-perimeter shapefiles and tables with event- or daily-level statistics, including measures of fire size, duration, and spread.

    BUG ALERT

    • Many of the data products created in Fall 2021 may be shifted by a half pixel, and may lack a coordinate reference system.
    • The problem is now fixed, so this will not affect new iterations of firedpy.
    • Sometimes the server that houses the MCD64A1 product used by firedpy is down. If this happens, you just need to wait until it comes back up.
    • See the issues tab for more bugs, or to report a new bug!
